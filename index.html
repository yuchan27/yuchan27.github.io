AI ENGINEERING 實作經驗

Hybrid RAG把資料接進回答，而不只接進模型。

以 TypeScript 串接關鍵字檢索、向量搜尋與重排序，將知識整理成模型可用的上下文。關注檢索品質、租戶資料隔離，以及效果與成本的取捨。

TypeScriptpgvectorHybrid RAGReranking
工程筆記 +

檢索流程：關鍵字 + embedding 語意搜尋 → 候選合併去重 → BGE reranker → 上下文組織。

後端設計：PostgreSQL / pgvector、租戶知識隔離、重排序失敗時的 fallback，以及可追蹤的回覆紀錄。

此處為實作摘要，不公開私有程式碼或業務資料。
